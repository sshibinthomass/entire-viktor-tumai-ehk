The rule2:00–2:45

Two probabilities, one threshold.

p1, p2 = P(D≤1), P(D≤2)   # TF-IDF(first user msg)
                         #   ⊕ 23 rank features

tier = 1 if p1 ≥ τ         # τ = 0.80
       2 if p2 ≥ τ
       3 otherwise         # per task, never per call

Fallbacks: p3 = min(p2, p3) · no user text → numeric ranks alone · unseen values → clamped by frozen ECDFs · no artifact → --method score

What it reads

A rule a judge can restate beats a better score they cannot explain. The signs are the insight: a dense ask is hard, a broad toolset is not. One tier per task, so a model switch never resets the prefix cache mid-trajectory.
