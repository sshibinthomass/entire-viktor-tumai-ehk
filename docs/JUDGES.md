# Judge's guide

Everything you need to evaluate this submission in ~15 minutes: what to look at,
which committed artifact backs every claim, how to try to break it, and how to
run it on your own data.

## The 5-minute look

```bash
python -m http.server 8017 -d dashboard
```

- **http://localhost:8017/present.html** — the 5-minute deck. Every number is
  computed in your browser from `data.js` + `findings.js` (both generated by the
  pipeline, both committed); nothing on a slide is hand-typed except prose.
- **http://localhost:8017/** — the interactive lab. Same math, every
  hyperparameter live: router method (blend / heuristic / τ / λ / k-means),
  α/τ/λ, group weights, evaluator weights and cuts, overrides, tier prices,
  cache-aware vs cache-blind costing. Hover anything for what it means.

The one chart is the **cost–quality frontier**: share of tasks served
(tier ≥ observed difficulty) vs estimated cost relative to sending everything to
the top tier, swept over the active method's own knob, drawn against expected
random routing, the repriced logged dispatch, and the always-top-tier dot.

## The rigor checklist (things you should try to break)

1. **No routing-time leakage.** `router/features.py` reads only the system
   prompt, the first user message and the tool definitions. The logged `model`
   id never enters features or labels (grep for `model` in `router/`).
2. **Out-of-fold everywhere.** GroupKFold(5) on a workspace fingerprint (710
   groups — `router/ml.py:workspace_of`); TF-IDF vocabularies, rank transforms
   and classifiers are fit per training fold.
3. **No test-label leakage in dispatch.** Tier cuts are calibrated on each
   fold's TRAIN labels/scores (`experiments.py:cut_dispatch_oof`). The pooled
   "known-marginals" variant is reported alongside, labeled as transductive.
4. **λ-Bayes is deployable.** The dispatch rule sees an OOF *prediction* of each
   task's cost, never its realized size. Rows named `lambda-oracle` in the
   benchmark are the hindsight upper bound and are excluded from winner picks.
5. **The evaluator is frozen while the router is tuned**, and its ceiling is
   quantified: 30 perturbed evaluator configs agree 94.9% with the frozen one
   (`results/tuning_report.json → evaluator_label_agreement`) — router
   agreement above that is unmeasurable.
6. **Reconstruction is validated, not assumed.** The loader groups on
   system + full first-user text and asserts item-prefix nesting
   (`scripts/load_trajectories.py`); under this key, all 25 multi-call
   trajectories are single-model — the premise holds exactly.
7. **Python ↔ JS parity.** The dashboard ports the same right-ECDF rank
   transform (`rank_utils.py` ↔ `ranksOf` in `dashboard/index.html`); the lab's
   default tiles reproduce `results/comparison.json` to the digit.

## Run it on your own data

Any export in the challenge format works (one JSONL line per request:
`model`, `input`, `tools`).

**Mode A — held-out, zero refitting** (the honest test):

```bash
mkdir -p export && tar xzf your_chunk.jsonl.tar.gz -C export/
python scripts/load_trajectories.py export/               # sanity + validator stats
python scripts/enrich_dataset.py export/ export_linked/   # assign ids
python freeze_router.py export_linked/trajectories_v1_01.jsonl   # one-time freeze on our fit chunk
python apply_frozen.py export_linked/your_chunk.jsonl     # -> results/heldout_report.json
python apply_frozen.py --one one_request.json             # or route a single task
```

**Mode B — full pipeline on your data**: replace the chunks in `export/`, run
the reproduction steps in [README.md](../README.md), reload the dashboard —
every chart and finding recomputes from your data.

Setup: Python ≥3.11, `pip install -e .` (numpy / scipy / scikit-learn). No GPU,
no API keys (the optional `judge_rescore.py` uses your own key if set).

## Known weaknesses (named on the deck, quantified in the repo)

- Difficulty = **observed effort**, partly shaped by the model that served the
  task. Quantified by the matched check; correctable with
  `run_pipeline.py --residualize`; the default stays unresidualized so headline
  and correction are separately inspectable.
- **Token counts are chars/4 estimates** (no `usage` in the export); dollar
  figures are labeled input-only where applicable and carry a tier-price
  sensitivity. Quote ratios, not dollars.
- The cache-trap dollar figure is **modeled** (assumptions in the JSON); the
  measured multi-call subset is a floor because sampled logging hides switch
  points.
- Tercile tier assignment forces three ids per tier; per-model bootstrap
  stability shows which boundaries are fuzzy.
